Install steps

Mac

  1. Open the downloaded disk image.
  2. Drag wasync to Applications.
  3. Open wasync from Applications.
  4. Scan the code with WhatsApp on your phone: Settings, Linked devices.

Windows

  1. Run the Setup file.
  2. Read the note and choose I accept.
  3. Finish with "Open wasync now" ticked.
  4. Scan the code with WhatsApp on your phone: Settings, Linked devices.

Linux

  1. Unpack and install: 
    mkdir wasync && cd wasync
tar -xzf ~/Downloads/wasync_VERSION_linux_ARCH.tar.gz
./install.sh
  2. Run wasync setup and scan the code.

Or with Homebrew:

brew tap --custom-remote gehariharan/tap https://github.com/gehariharan/wasync.git
if brew help trust >/dev/null 2>&1; then brew trust --formula gehariharan/tap/wasync; fi
brew install gehariharan/tap/wasync-axi

Homebrew on Mac and upgrade details: Homebrew installation.
