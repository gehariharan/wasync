wasync_

Your WhatsApp groups,
on your computer.

Archive the groups you choose into a local SQLite database. Browse in your terminal, search your messages, and give your agents a CLI that reads by default.

Install wasync ↓Explore the source ↗

macOS 15+ · Intel & Apple Silicon · Linux · MIT license

01

Choose what you keep.

Pair using WhatsApp Linked Devices, then enable the groups you want. Capture new messages and request the history WhatsApp makes available.

02

Keep it local.

Text and message metadata live in SQLite. Search with full-text queries or read the database from your own tools.

03

Let your agents read.

Query groups, messages, search results, and sync status as JSON. The query CLI works alongside the TUI without opening a second WhatsApp session.

Get started

Install once. Keep it yours.

No Go compiler needed. Mac downloads are Developer ID signed and notarized.

Homebrew

Recommended on Mac
brew tap --custom-remote gehariharan/tap https://github.com/gehariharan/wasync.git && brew install --cask gehariharan/tap/wasync

Then run wasync to open the TUI and pair your account. Already installed? Run brew tap --custom-remote gehariharan/tap https://github.com/gehariharan/wasync.git, then brew update and brew upgrade --cask gehariharan/tap/wasync.

Or download a prebuilt installer

Release notes ↗

Use Homebrew or the .pkg installer as your installation method. Quit capture before upgrading; your archive and pairing state stay in your user data directory.

Linux downloads & setup

Linux x86-64 ↓ · Linux ARM64 ↓ · glibc 2.35 or newer

Extract the archive and install the executable on your PATH:

mkdir -p "$HOME/.local/bin"
install -m 755 wasync "$HOME/.local/bin/wasync"
export PATH="$HOME/.local/bin:$PATH"
wasync

Latest builds and checksums are available on GitHub Releases.

For your tools & agents

A small CLI.
A useful local archive.

Point an agent at the query commands. Results are JSON, and queries never send messages or change your archive. Replies, reactions and edits are available only to agents you explicitly grant them, and message text is treated as untrusted.

To set one up, run wasync agents grant NAME --scope … --on-demand, then approve each chat by name when the agent asks. Set up an agent, start to finish.

Read the CLI documentation ↗
# See your enabled groups
wasync query groups --enabled

# Search your local messages
wasync query search "meeting"

# Pull a page of messages
wasync query messages \
  --group 'GROUP_ID' --limit 50

A note before you pair

wasync uses the unofficial whatsmeow library. WhatsApp may change its protocol or restrict unofficial clients. History is best effort and may be incomplete; reconnecting does not guarantee every missed message was recovered. Only archive conversations with appropriate permission.
